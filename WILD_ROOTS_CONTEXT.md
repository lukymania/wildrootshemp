Major e-tailers (Amazon, eBay, Walmart, Facebook/Instagram ads, Google Shopping) block "CBD" products but allow "hemp" products. All products use "Nano-Hemp" as the primary ingredient term. Never use "CBD," "cannabidiol," or "hemp extract" on any packaging or marketing.

## 4. TERMINOLOGY SWAP GUIDE

| Never Use | Always Use |
|-----------|------------|
| CBD | Nano-Hemp |
| NanoCBD | Nano-Enhanced Hemp Extract (or just Nano-Hemp) |
| CBD Oil | Hemp Tincture / Nano-Hemp |
| CBD Isolate | Hemp-Derived Compound (or Nano-Hemp) |
| Cannabidiol | Hemp Extract / Nano-Hemp |
| High Potency | Extra Strength / Maximum Strength |
| Pain Pen | Relief Roll-On |
| Pain Spray | Relief Spray / Botanical Mist |
| Pain | Relief / Comfort / Ease |
| Sleepy Time | Deep Rest / Evening Formula |
| For Pain | For Targeted Relief / For Comfort |

### Approved Marketing Language
- "Supports overall wellness"
- "Promotes a sense of calm"
- "Supports restful sleep"
- "For daily wellness rituals"
- "Fast-absorbing botanical relief"
- "Nano-enhanced for better absorption"

### Never Use
- "Treats pain"
- "Cures anxiety"
- "CBD product"
- "Cannabidiol"
- Any medical/disease claims
