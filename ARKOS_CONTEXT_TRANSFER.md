## Technical Architecture
- **Hosting**: GitHub Pages with custom domains
- **DNS**: A records pointing to GitHub Pages IPs (185.199.108/109/110/111.153)
- **SSL**: HTTPS via GitHub Pages (CNAME must match root domain, no www prefix)
- **Charts**: D3.js v7 scatter plots with `viewBox="0 0 900 520"`, log scales, tooltips
- **SEO**: Schema.org JSON-LD (FAQPage, HowTo, Product, Review, Organization, WebSite, BreadcrumbList, Dataset)
- **AI/GEO Meta**: `ai-purpose`, `ai-content-type`, `ai-expertise`, `ai-confidence` tags
- **Responsive**: Mobile hamburger menus, grid breakpoints at 768px and 480px

## Known Bugs Fixed (Don't Reintroduce)
1. **"Rankings insertion bug"**: Never search for "ranking" to insert content — found inside `<meta name="keywords">` and destroyed page structure
2. **Header CSS missing on sub-pages**: Always extract full header CSS from homepage when creating guide/chart pages
3. **Invisible stars on dark backgrounds**: Never use `☆` (U+2606 WHITE STAR) on dark themes — use `<span style="opacity:0.18">★</span>`
4. **Tooltip offset from cursor**: Tooltip `<div>` must be direct child of `<body>`, NOT inside a container with CSS transforms (like `.reveal` sections with `transform: translateY()`)
5. **CNAME mismatch causing SSL failures**: CNAME file must contain root domain (e.g., `thecbdreviewers.com`) not `www.thecbdreviewers.com`
