## Deployment Instructions

### Option 1: GitHub Pages (Free Hosting)

Each site should be deployed to its own repository. For GitHub Pages:

1. **Create 5 separate GitHub repositories** (one per domain)
2. Upload the `index.html` and `assets/` folder to each repo
3. Enable GitHub Pages in repo settings (branch: `main`, folder: `/ (root)`)
4. Your sites will be live at `https://yourusername.github.io/repo-name/`

### Option 2: Static Web Host (Netlify, Vercel, Cloudflare Pages)

Upload each site's folder to the platform of choice.

### Option 3: Traditional Web Hosting (cPanel/FTP)

Upload each folder's contents to the respective domain's public_html directory.

## Google Search Console Setup

After deployment:
1. Verify each domain in [Google Search Console](https://search.google.com/search-console)
2. Submit sitemaps (create sitemap.xml for each site)
3. Request indexing for all pages
4. Add structured data testing via [Rich Results Test](https://search.google.com/test/rich-results)
